# Модель метрик

## Главный экран владельца

| Показатель | Источник | Смысл |
|---|---|---|
| Расходы | Google Ads | Сколько потрачено за период |
| Конверсии | Google Ads | Конверсии, включённые в колонку `Conversions` |
| CPA | Google Ads | Расходы / конверсии |
| Ценность / расходы | Google Ads | Conversion value / cost; требует корректных values |
| Сеансы | GA4 | Посещения сайта по reporting identity property |
| Клики из поиска | Search Console | Бесплатные переходы из Google Search |

## Диагностический слой

После подключения источников аудит должен отдельно проверить:

- что `denoise_booking_success` зарегистрирован в GA4 и помечен key event;
- что одна реальная запись создаёт ровно одну конверсию;
- какая Ads conversion action является primary и входит в bidding;
- не считаются ли клики по меню, WhatsApp и кнопкам записи как равнозначные бизнес-конверсии;
- передаётся ли корректная сумма услуги и `EUR`;
- совпадают ли часовые пояса GA4, Ads, Search Console и Altegio;
- сохраняется ли click ID (`gclid`, `gbraid`, `wbraid`) до момента записи;
- как учитываются отмены и переносы из Altegio.

До завершения проверки не следует оптимизировать ставки по общей колонке «Все конверсии» и менять бюджеты только на основании текущего tracking.
